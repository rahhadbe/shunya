# Something Is Expensive

Use this family when a system consumes more money, compute, storage, network capacity, or engineering effort than its value justifies.

## What engineers notice

- cost rises faster than usage or business value
- a small workload dominates resource consumption
- a budget or capacity limit approaches without a clear owner

## Questions to ask first

1. What resource is expensive, and how is its cost measured?
2. Which request, tenant, operation, or lifecycle stage drives the cost?
3. Is the cost necessary, accidental, or a trade-off for another requirement?
